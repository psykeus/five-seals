# THE FIVE SEALS - world data
# -------------------------------------------------------------
# Map legend (16 x 11 metatiles per screen):
#   .  grass          ,  path          T  tree         R  rock
#   ~  water / lava   #  bramble (burn) C  cave (warp)  V  veil wall (rock)
#   =  veil bridge    A  statue/sign   W  wall (mossy outdoors, brick in temple)
#   F  floor          D  door (shut)   O  door (open)  B  brazier (unlit)
#   L  brazier (lit)  S  stairs (warp) v  veil wall (brick)  X  void
#   "  flowers
#
# Screen keywords:
#   pal <set>                 palette set (OW_ROCK OW_WATER TEMPLE_WALL TEMPLE_LAVA CAVE)
#   msg <NAME> [onenter]      message for statues; onenter = show once on first visit
#   shrine <x> <y>            checkpoint + autosave, respawn tile
#   enemy <type> <x> <y>      blob | stalker | shade | boss
#   item <type> <x> <y>       tome | sigil | heart | seal
#   warp <area> <gx> <gy> <x> <y>   target of cave/stairs tiles on this screen
#   cond clear|braziers|flag <area> <gx> <gy>   what opens shut doors (D)
#   solvemsg <NAME>           message shown when the room is solved
# Edges: walking off an edge enters the neighbouring screen in the same area grid.
# -------------------------------------------------------------
